Zhuyin slots accept any order. A new symbol replaces the same slot until you enter a tone.

␣
A space isn’t always a space.

In Zhuyin, Space completes a first-tone syllable. Press Space again to insert a separator before another language. Elsewhere, Space is preserved and permits a language change.

Expandable dictionary, real decoding

Several interpretations compete as you type. Language changes require literal spaces; first-tone spaces remain inside Chinese segments. Scores are simple heuristics, not confidence percentages.

The shared Rust engine runs locally in your browser through WebAssembly. This playground is not yet a system-wide IME.

Try these Japanese readings

Romaji now composes hiragana and katakana beyond the word dictionary: sakura → さくら, gakkou → がっこう, ryokou → りょこう, ko-hi- → コーヒー (choose the alternative). Try shinyou → しにょう versus shin'you → しんよう. Pending consonants stay visible while typing.

Kanji conversion still uses a small word map: tiisai / chiisai, neko, inu, nihongo, arigatou, konnichiha, sushi, suki, ookii, kawaii, ohayou, watashi, tokyo. Automatic language ranking is experimental; select another candidate when needed.

Zhuyin: reorder and replace

Enter 聲母, 介音 and 韻母 in any order. The latest symbol in each slot wins. A tone key (Space, 6, 3, 4 or 7) finalizes that syllable; subsequent symbols start a new one.

us3lc3 → 你好 · /j5␣ → 中. Try “Replace before tone” and replay it to watch all three slots change. Unknown syllables remain in Zhuyin; the dictionary is still limited.
